# Kiddo — il mercatino dei piccoli

Un marketplace in stile Vinted per abiti, scarpe, giochi, libri e accessori per bambini. Next.js 15, TypeScript, Tailwind CSS 4.

> Progetto dimostrativo: pagamenti e spedizioni sono simulati.

## Funzionalità
- Catalogo di 16 annunci con foto reali
- Ricerca e filtri per categoria, età/taglia, condizione, prezzo e marca
- Scheda prodotto con galleria, venditore e acquisto demo
- Preferiti, chat, pubblicazione annunci con caricamento foto, profilo

## Avvio
```bash
npm install
npm run dev
```

## Build
```bash
npm run typecheck
npm run build
```

Nessuna variabile d'ambiente richiesta. Le foto sono in `public/products` con attribuzioni in `CREDITS.json`.
